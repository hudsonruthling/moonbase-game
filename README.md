# LUNAR OUTPOST

## Download and play

- **[Download LUNAR OUTPOST as an HTML file](download.html)** — save `LUNAR-OUTPOST.html`, then open it in a web browser.
- **[Download the repository as a ZIP](https://github.com/hudsonruthling/moonbase-game/archive/refs/heads/main.zip)** — this ZIP contains the project files.

GitHub's preview shows source code; it does not run the game. The HTML download preserves the existing game mechanics and updates its displayed title to LUNAR OUTPOST.
