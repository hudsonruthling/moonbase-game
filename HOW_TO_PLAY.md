# How to Play Our Game

Welcome, NASA judges! **Moon Base Trade-Offs** is a browser game about the choices involved in keeping a lunar outpost and its crew safe. The game is a simplified educational prototype; it is not an official NASA product and does not use live NASA data.

## Open and play the game

The game file is [`Main Game HTML`](Main%20Game%20HTML) in this repository. It contains the complete game, but it does not have a `.html` file extension.

1. Open [`Main Game HTML`](Main%20Game%20HTML) in the repository and choose **Download raw file** (or open **Raw** and save the file).
2. On your computer, rename the downloaded file to `moonbase-game.html`. Make sure the name ends in `.html`, not `.txt`.
3. Open `moonbase-game.html` in a recent web browser, such as Chrome, Edge, Firefox, or Safari. The game should start in the browser; no installation or server is needed. An internet connection allows the game to load its optional web font.

**GitHub's file preview is not a playable game:** it displays the HTML source. This repository does not currently have a published GitHub Pages game URL, so there is not yet a link that runs the game directly from GitHub. To offer that option, the repository owner would need to publish a Pages site and provide it with an `index.html` entry point; the current game file would need to be published under that name. Once configured, GitHub provides the site's URL in **Settings → Pages**.

## Play

- The first screen is the mission setup. Choose a solar year and base site, allocate up to six extras, then select **Launch!**
- The in-game **? HOW TO PLAY** button opens the interactive tutorial. It also opens automatically the first time you play.
- Move with **WASD** or the **arrow keys**. On a phone or tablet, use the on-screen arrows.
- Get near a building and press **E** or **Space**, or use the on-screen **Use** button. You can also select an action card to send your astronaut to that facility and perform the action.
- Each day, manage power, air, food, and radiation dose. Actions use crew time and power. End the day when you are ready.
- The mission lasts 12 days. Keep the crew alive, keep radiation dose below 100, and complete at least five science walks to succeed. Every choice involves a trade-off.

The game includes “Did you know?” science notes and a **Where the science comes from** section. Gameplay quantities and outcomes are simplified for play; they should not be read as real mission-planning or medical guidance.
